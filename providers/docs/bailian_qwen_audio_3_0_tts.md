# 百炼 Qwen Audio 3.0 TTS 能力说明

## 概述
Qwen-Audio-TTS 是阿里云百炼提供的非实时语音合成服务，支持通过 HTTP API 将文本转换为语音。

**适用模型**：`qwen-audio-3.0-tts-flash`、`qwen-audio-3.0-tts-plus`
**地域限制**：仅华北2（北京）地域可用
**音频有效期**：生成的音频 URL 有效期为 24 小时

---

## 核心参数

### 必填参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `text` | string | 待合成文本。可嵌入情感标签和富语言标签来控制语音表现力。 |

### 可选参数（由你控制）

| 参数 | 类型 | 范围 | 默认值 | 说明 |
|------|------|------|--------|------|
| `instruction` | string | - | - | 自然语言指令，用于控制方言、情感或角色。例如："请用河南话表达"、"语速较快，带有上扬语调" |
| `volume` | integer | 0-100 | 50 | 音量大小 |
| `rate` | float | 0.5-2.0 | 1.0 | 语速倍率 |
| `language_hints` | array | 见下方枚举 | - | 指定语音合成的目标语言。建议与文本语种一致，以提升合成效果 |

### `language_hints` 枚举值
`zh`（中文）、`en`（英语）、`fr`（法语）、`de`（德语）、`ja`（日语）、`ko`（韩语）、`ru`（俄语）、`pt`（葡萄牙语）、`th`（泰语）、`id`（印尼语）、`vi`（越南语）、`es`（西班牙语）、`it`（意大利语）、`ms`（马来西亚语）、`fil`（菲律宾语）、`ar`（阿拉伯语）

## 使用示例

### 示例 1：情感标签 + 富语言标签
```
文本：[excited]今天的天气真不错！[laughing]我们一起出去玩吧！
效果：兴奋的语气朗读，在“真不错！”之后插入笑声
```

### 示例 2：切换情感
```
文本：[serious]请注意安全事项。[excited]好了，现在让我们开始吧！
效果：第一句严肃，第二句切换为兴奋
```

### 示例 3：指令控制方言
```
text: 叫你去买盐，你买回来一袋面，这不是弄啥嘞吗！
instruction: 请用河南话表达。
```

### 示例 4：完整参数调用（通过工具）
```json
{
  "text": "[excited]今天天气真好！我们出去玩吧",
  "instruction": "语速较快，带有上扬语调",
  "volume": 60,
  "rate": 1.2,
  "language_hints": ["zh"]
}
```

## 你的任务

根据对话上下文和待合成的原始文本，选择合适的参数：

1. **判断情感**：根据上下文的语气（开心、悲伤、严肃等），在 `text` 中添加对应的控制类标签
2. **插入效果**：在合适的位置插入富语言标签（如笑声、叹息）
3. **控制细节**：如需方言、特殊语速或音量，通过 `instruction`、`rate`、`volume` 参数调整
4. **语言匹配**：若文本含有多语言或数字/符号朗读异常，通过 `language_hints` 指定目标语言

**输出方式**：直接调用 `tts_enhance` 工具，将参数填入对应字段。
