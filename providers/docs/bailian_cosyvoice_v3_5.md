# 百炼 CosyVoice v3.5 TTS 能力说明

## 概述
CosyVoice v3.5 是阿里云百炼提供的非实时语音合成服务，支持通过 HTTP API 将文本转换为语音。

---

## 核心参数

### 必填参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `text` | string | 待合成文本。 |

### 可选参数（由你控制）

| 参数 | 类型 | 范围 | 默认值 | 说明 |
|------|------|------|--------|------|
| `instruction` | string | - | - | 自然语言指令 |
| `volume` | integer | 0-100 | 50 | 音量大小 |
| `rate` | float | 0.5-2.0 | 1.0 | 语速倍率 |
| `pitch` | float | 0.5-2.0 | 1.0 | 音调倍率 |
| `language_hints` | array | 见下方枚举 | - | 指定语音合成的目标语言。建议与文本语种一致，以提升合成效果 |

### `language_hints` 枚举值
`zh`（中文）、`en`（英语）、`fr`（法语）、`de`（德语）、`ja`（日语）、`ko`（韩语）、`ru`（俄语）、`pt`（葡萄牙语）、`th`（泰语）、`id`（印尼语）、`vi`（越南语）

## 自然语言指令（`instruction`）

指令控制通过自然语言描述控制语音的音调、语速、情感和音色特点，无需调整复杂的音频参数。

### 如何编写高质量的声音描述

核心原则：

- 具体而非模糊：使用描绘声音特质的词语，如 “低沉”、“清脆”、“语速偏快”，避免 “好听”、“普通” 等主观或模糊的表述。
- 多维而非单一：好的描述通常涵盖多个维度（如性别、年龄、情感等）。仅写 “女声” 过于宽泛，难以生成有特色的音色。
- 客观而非主观：聚焦声音的物理和感知特征。例如，用 “音调偏高，带有活力” 代替 “我最喜欢的声音”。
- 原创而非模仿：描述声音的特质，而非要求模仿特定人物（如名人、演员）。模型不支持模仿，且可能涉及版权风险。
- 简洁而非冗余：确保每个词都有明确作用，避免重复的同义词或无意义的修饰。

描述维度参考：

建议组合以下维度描述声音，维度越丰富，生成效果越精准。

| **维度** | **描述示例** |
| --- | --- |
| 性别  | 男性、女性、中性 |
| 年龄  | 儿童（5-12 岁）、青少年（13-18 岁）、青年（19-35 岁）、中年（36-55 岁）、老年（55 岁以上） |
| 音调  | 高音、中音、低音、偏高、偏低 |
| 语速  | 快速、中速、缓慢、偏快、偏慢 |
| 情感  | 开朗、沉稳、温柔、严肃、活泼、冷静、治愈 |
| 特点  | 有磁性、清脆、沙哑、圆润、甜美、浑厚、有力 |
| 用途  | 新闻播报、广告配音、有声书、动画角色、语音助手、纪录片解说 |

## 方言

通过自然语言指令（`instruction`）参数控制方言，例如：

```json
{
  "instruction": "请用河南话表达"
}
```

### 支持的方言

普通话、广东话、东北话、甘肃话、贵州话、河南话、湖北话、江西话、闽南话、宁夏话、山西话、陕西话、山东话、上海话、四川话、天津话、云南话

## LaTeX 公式朗读（仅支持中文）

CosyVoice v3.5 支持解析文本中嵌入的 LaTeX 公式，并按中文阅读习惯朗读，适用于在线教育、有声读物等包含数学公式的场景。该能力直接作用于 `text` 字段，无需任何额外参数。

### 使用方法

将数学公式用分隔符包裹后嵌入 `text` 即可。支持的分隔符（任选一种，效果相同）：

- `$...$`
- `$$...$$`
- `\(...\)`
- `\[...\]`

示例：

```text
这是一道一元二次方程的求根公式：$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$，请仔细计算。
```

模型会朗读为：“x 等于负 b 加减根号下 b 的平方减四 ac，分之二 a”。

### 使用限制

- **语种**：仅支持中文。
- **内容**：公式内容必须在下方“支持的符号”范围内；不支持 Markdown 数学公式（如 ` ```math ... ``` `）；分隔符内应仅包含公式内容，混入非公式文本可能导致朗读不准确。
- **转义**：在 JSON 请求体或编程语言字符串中，反斜杠 `\` 是转义字符，需要写成 `\\`。例如 LaTeX 命令 `\frac` 在代码中应写作 `\\frac`。
- **模型**：本插件对应的 `cosyvoice-v3.5-plus`、`cosyvoice-v3.5-flash` 支持该能力。

## 使用示例

### 示例 1：指令控制方言
```json
{
  "text": "叫你去买盐，你买回来一袋面，这不是弄啥嘞吗！",
  "instruction": "请用河南话表达。"
}
```

### 示例 2：调整语速、音量和音调
```json
{
  "text": "各位听众朋友们，欢迎收听今天的节目。",
  "rate": 0.9,
  "volume": 60,
  "pitch": 1.1
}
```

### 示例 3：综合使用指令和语言提示
```json
{
  "text": "Hello everyone, this is a test.",
  "instruction": "温柔的女性声音，语速偏慢",
  "language_hints": ["en"],
  "volume": 70,
  "rate": 0.8
}
```

## 你的任务

根据对话上下文和待合成的原始文本，选择合适的参数：

1. **结合上下文选择合适的情感描述**：通过 instruction 描述语音的情感或角色特点以及可能需要的方言。
2. **调节语音细节**：如需控制语速、音量、音调，分别设置 rate、volume、pitch 参数。
4. **语言匹配**：若文本含有多语言或数字/符号朗读异常，通过 `language_hints` 指定目标语言

**输出方式**：直接调用 `tts_enhance` 工具，将参数填入对应字段。
